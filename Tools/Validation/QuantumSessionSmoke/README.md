Copy it there only after the agent owning that project releases its Unity process. Arguments are SessionRunner.Arguments with Local mode, one local player slot, null Communicator, seed42, the actual MazeMayhem Map, actual project SimulationConfig and seventeen native custom config assets, BattleRoyale mode, team size1, bots enabled and the native default session config.
