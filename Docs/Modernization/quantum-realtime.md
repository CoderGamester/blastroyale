# Quantum 3 Realtime client port

The existing network/room interfaces now call the actual Photon Realtime API shipped with Quantum 3.0.14. RealtimeClient replaces QuantumLoadBalancingClient/LoadBalancingClient; Photon.Client.PhotonHashtable and EventData replace old client namespaces; room and event operations use EnterRoomArgs/RaiseEventArgs. Peer time and RTT measurements use RealtimePeer.ServerTimeInMilliseconds and Stats.LastRoundtripTime, retaining the SDK's long RTT values without narrowing.

GameNetworkService copies the configured server AppSettings, explicitly selects the configured Quantum application ID and uses ConnectUsingSettings for connection/region selection. It assigns the player's nickname directly. The property/callback wire keys, original room setup and TTL values remain. PlayerProperties was removed from EnterRoomArgs because the real SDK obtains the previously reset LocalPlayer.CustomProperties when sending room operations. LeaveRoom uses the current one-argument API.

ServerListService uses GetRegions and its built-in ping workflow. Results and events are applied once on the existing main-thread dispatcher, including the normal SDK disconnect that occurs before region-result notification. A failed connection becomes Failed instead of leaving a pending Connecting status. Polling uses real-time delay so a paused loading screen still services the peer. No application ID or credential value is printed by this port.

Async room join/create now reject their completion task when Photon refuses the operation synchronously, instead of waiting forever for a callback that will not be produced. Kick handling ignores a mismatched payload and checks room presence before dereferencing it. Original authorization still requires the kick sender to be the current master client.

Validation: a real whole-game C# compile against the native imported SDK reaches all method bodies with zero diagnostics in the owned Server/Room files (GameRoom is root-owned), NetworkState and the two cleaned Logic files. At the recorded check, 47 unrelated client diagnostics remained in root/editor-agent scopes, so this is not a whole-client success claim. Reproduce with python3 .local/compile-q3-backend.py; output is isolated from other agents at .local/quantum3-client-backend-compile and artifacts/quantum3-backend-firstlight.game-compile.log. No Unity, live Photon connection, PlayFab call or device test was run for this port.
