# UI Toolkit serialization migration

Status: **Source port and isolated compiler checks passed; full Unity and visual checks pending**.

Unity 6000.3 deprecates `UxmlFactory`/`UxmlTraits`. All 64 registered controls in `Game/UIElements` and `Game/Presenters` now use `[UxmlElement]` partial classes and generated `UxmlSerializedData`. Namespaces, class names, UXML tags and source `.meta` files are preserved. All existing custom attribute names remain declared; there are 75 modern attribute declarations. No deprecation warning was suppressed. This follows the official [Unity 6.3 custom-control migration guide](https://docs.unity3d.com/6000.3/Documentation/Manual/ui-systems/migrate-custom-control.html).

The implementation preserves the behavior previously hidden in `UxmlTraits.Init`: localization updates labels, popup title/glow/close properties change their child elements, image buttons retain enabled/focus defaults, password fields start masked, tooltip direction and radial progress repaint, font bounds remain clamped to at least one, safe-area flags update the appropriate margins, and kit buttons apply shape/color/style/icon/text. `LabelOutlined` builds the outline child in its constructor and rebuilds it when its attribute changes; callbacks are registered once and safely handle a disabled outline. Obsolete annotations on supported parameterless UXML constructors were removed.

Composite news, shop and battle-pass preview rendering runs through the panel scheduler after the complete set of attributes is applied. Runtime `SetData` cancels pending preview updates and prevents later panel attachment from replacing player/catalog data. Empty news images do not request a texture; editor shop previews do not dereference an uninitialized real-money IAP product. Battle-pass debug previews now use the requested state/premium attributes, which the original trait overwrote with hard-coded values. Animation setters coalesce initialization, stop animations when detached, preserve defaults, and avoid zero-duration/division behavior. The duplicated old `rand-pos-min-x` declaration for the Y minimum is corrected to `rand-pos-min-y`; no retained UXML asset uses either spelling.

The old currency schema allowed no UXML children; `[UxmlElement("CurrencyDisplayElement", new Type[0])]` preserves that contract. Currency values are validated against the actual `GameIdGroup.Currency`. Modern Unity enum inspectors show the enum rather than the legacy custom `UxmlEnumeration` subset; the runtime guard rejects a non-currency selection. The legacy `Required`/`Optional` schema hints are replaced by property defaults, as required by the modern serializer; required attributes continue to use their original names.

Four old derived factories mistakenly registered their base/other types. Modern registration exposes their actual derived names (`CurrencyRewardSummaryItemElement`, `GameIdIconSummaryItemElement`, `ProfilePictureRewardSummaryItemElement`, `StoreCreatorCodeElement`). No retained UXML/USS asset refers to those formerly misregistered derived names, so no aliases or tag rewrite was needed. Legitimate `RewardSummaryItemElement` tags remain unchanged. See `uxml-registration-only.json` for the supporting scan.

Related Unity 6 visual-element transforms in `AnimatedImageElement`, `JoystickElement`, `SpecialButtonElement` and `PlayerStatusBarElement` use `style.translate`, `style.rotate`, `style.scale` and `resolvedStyle` reads. This replaces deprecated UI `ITransform` access without affecting ordinary Unity component transforms.
